# 🚀 DevPath বাংলা

**শূন্য থেকে Full-Stack Web Developer হওয়ার বাংলা Interactive Roadmap।**

DevPath বাংলা একটি বিনামূল্যের, ওপেন-সোর্স ওয়েব অ্যাপ। যারা বাংলায় Web Development শিখতে চায়, তাদের জন্য এটি তৈরি করা হয়েছে।

## ✨ Features

- 📚 Step-by-step learning roadmap
- 📊 Live learning progress tracker
- 💾 Automatic progress saving with Local Storage
- 🔎 Search learning topics
- 🎯 Filter by difficulty level
- 🌙 Dark and Light mode
- 📱 Responsive mobile-friendly design
- ⚡ No framework or paid API required

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
